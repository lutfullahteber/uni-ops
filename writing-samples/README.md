# Writing Samples

Drop your personal writing samples here (past essays, motivation letters, blog posts, professional emails) so uni-ops can calibrate the tone of generated SoPs, motivation letters, and recommender request emails to your voice.

Any file in this directory **except `README.md`** is scanned for style markers (tone, sentence length, vocabulary, voice). Personal identifiers are stripped — only abstract style descriptors are kept and cached in `modes/_profile.md` under `## Writing Style`.

Re-run style calibration after adding new samples by asking uni-ops to "recalibrate writing style".
